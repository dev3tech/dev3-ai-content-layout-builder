DEV3 AI Content & Layout Builder

AI writing, layouts and image descriptions inside Elementor, WPBakery, the block editor and the Media Library. Version 1.0.0 · by DEV3 Technologies.

Installation

  1. In your Envato download, find dev3-ai-content-layout-builder.zip (the installable plugin — do not upload the whole bundle).
  2. WordPress admin → Plugins → Add New → Upload Plugin → choose the zip → Install Now → Activate.
  3. A new DEV3 AI Builder menu appears in the admin sidebar.

Requirements: WordPress 6.0+, PHP 7.4–8.3 with the OpenSSL extension, outbound HTTPS to generativelanguage.googleapis.com. Elementor 3.x+ and WPBakery 6.x+ are optional.

API key setup

  1. Open Google AI Studio → API keys and sign in with a Google account.
  2. Click Create API key and copy it (it starts with AIza).
  3. In WordPress go to DEV3 AI Builder → API Config, paste the key and click Validate & save. You should see “Connected — N models available”.
The key is encrypted in your database (AES-256-GCM, bound to your site's salts) and is never sent to the browser. Agencies can instead put it in wp-config.php:
define( 'DEV3CL_GEMINI_API_KEY', 'AIza...' );

The free tier is enough to try the plugin. For regular use, enable billing on the Google Cloud project behind the key — otherwise you may see “quota exhausted” messages.

Recommended models: gemini-2.5-flash for writing tasks and gemini-2.5-pro for the layout generator. Layouts take 15–45 seconds because the model plans the whole section.

The AI modal

Every integration opens the same compact modal.

  • Write — type what you want and click Generate (⌘/Ctrl+Enter), or use a quick action on the field's current content: Rewrite, Expand, Shorten, Summarize, Fix Grammar, Change tone ▾, Translate ▾. Heading fields add Headline ideas; the block editor adds SEO meta. Options lets you pick the model, tone, language and creativity for one request.
  • Result — preview, then Replace/Insert, Insert below (rich text), Edit, Copy, Regenerate or Discard.
  • Layout — describe a section, preview a wireframe, then Insert into page (or copy the WPBakery shortcode / download an Elementor template).
  • Image — pick a Media Library image or paste a URL and generate alt text, caption, title, description or promotional copy.
  • History — search and restore anything you generated before.

Elementor

  • Wand on every text field — a small ✦ next to the label of text, textarea, WYSIWYG and HTML-code controls in any widget (including third-party widgets).
  • “Write with DEV3 AI” button on Heading, Text Editor, HTML, Button, Icon Box, Image Box, Testimonial and Call to Action (Pro).
  • “Generate items with DEV3 AI” on Accordion, Toggle and Tabs fills the repeater with titled items (Elementor's placeholder items are replaced, your own are kept).
  • Generate a whole section — click the purple ✦ in the “Drag widget here” area (or press ⌘/Ctrl+Shift+G). Sections are inserted as native containers (or sections/columns on sites without the Flexbox Container feature) using free Elementor widgets, so everything stays editable.

Generated pricing tables can include a Monthly/Yearly toggle; it works on the live site and in the editor preview.

WPBakery Page Builder

  • Open any element's edit popup: text fields, textareas, the WYSIWYG editor and Raw HTML show a ✦ next to their label.
  • Text Block, Custom Heading, Button, Call to Action, Message Box, Toggle, Raw HTML, Tab/Accordion sections and Separator with Text also get an DEV3 AI Assistant param (gemini_ai_prompt) with a Write with DEV3 AI button.
  • Generate a section — click the ✦ in the WPBakery navbar. In the Backend Editor the rows are added directly; in other modes the shortcode is copied to your clipboard to paste in Classic Mode.

Block editor

  • Select a Paragraph, Heading, List, Quote, Verse or Preformatted block and click the ✦ Write with DEV3 AI button in the block toolbar.
  • On an Image block the same button writes alt text and a caption.
  • The DEV3 AI Assistant sidebar (✦ at the top right) has Write new content, Improve selected block and SEO title & description (applies the excerpt and slug).

Media Library

  • Open an image's details and click Generate alt text, caption & title, review, then Save to image.
  • List view → select images → Bulk actions → Generate missing alt text (AI). Up to 10 images without alt text are processed per run.

Prompt templates

Built-in: Landing Page Hero Copy, Product Description, FAQ List, Feature Grid, Pricing Table, SEO Meta, About Us, Testimonials Section, Call to Action, Blog Post Intro. Create your own under DEV3 AI Builder → Prompt Templates; every {placeholder} becomes a field in the modal, e.g.

Write a product description for {product} aimed at {audience}. Mention {usp}.

History & usage

Each user's generations are stored for the number of days set in General Settings (default 90) and mirrored in the browser for instant restore. Usage Logs show tokens reported by Gemini; check exact billing in Google AI Studio or the Cloud Console.

Updates

No licence key or activation is needed: every feature works as soon as the plugin is active. To update, download the latest version from your Envato Downloads page, then go to Plugins → Add New → Upload Plugin and upload the zip. WordPress offers to replace the installed version and keeps all your settings and data.

Troubleshooting

MessageFix
The Gemini API key is not validCreate a new key in AI Studio and paste it again.
Your Gemini quota is exhausted / rate limit reachedWait, enable billing on the key's Google Cloud project, or switch to another model.
The selected Gemini model is not availableAPI Config → Refresh models → pick one from the list.
Gemini is not available in your server's regionGemini API access depends on the server's location; use hosting in a supported region.
Your server could not reach the Gemini APIAsk your host to allow outbound HTTPS to generativelanguage.googleapis.com.
Gemini took too long to respondTry again; for layouts keep the description focused. Hosts with very short PHP time limits may need max_execution_time ≥ 120.
Gemini ran out of output tokensRaise Max Output Tokens or set Reasoning to Low.
Your session has expiredSave your work and reload the editor (the security nonce expired).
You are sending requests too quicklyThe per-user limit in General Settings was hit; wait a minute or raise it.
No ✦ buttons in the editorCheck the integration is enabled in General Settings and that your role can edit posts.

REST API: /wp-json/dev3cl/v1/ — generate, layout/convert, media/{id}, templates, history, usage, settings, models. All routes require a logged-in user with the right capability and a wp_rest nonce. In the editor, window.dev3cl.open( options ) opens the modal from your own code.

Privacy

Nothing is sent to Google until a user clicks an AI action. Then the prompt, the selected content and (for image actions) the image are sent to the Gemini API with your key, under Google's terms. History is stored in your own database and can be cleared by each user.tech. Consider mentioning AI-assisted content and Google Gemini in your site's privacy policy.
